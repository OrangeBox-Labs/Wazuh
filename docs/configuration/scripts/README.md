# Scripts de configuración

Este directorio está reservado para scripts auxiliares que formen parte de la configuración u operación de Wazuh, pero que no correspondan al instalador de agentes ni a una integración.

Actualmente no contiene scripts funcionales.

Cuando se agregue uno, deberá incluir documentación técnica con el mismo nombre base (`script.sh` + `script.md`, por ejemplo) y explicar propósito, dependencias, entradas, salidas, permisos, riesgos y pruebas realizadas.
